# Contributing to BetterCalapan

Thanks for your interest in contributing! 🧡

## Ways to Contribute

### Report Bugs

- Open an issue with steps to reproduce
- Include screenshots if possible

### Update Content

- Outdated info (phone numbers, officials, fees)
- Missing services or departments
- Typos and corrections

### Code Contributions

- Bug fixes
- New features
- Performance improvements

### Translations

- Filipino
- Mangyan languages

## Getting Started

```bash
# Fork and clone
git clone https://github.com/YOUR_USERNAME/portal.git
cd portal

# Install dependencies
pnpm install

# Start dev server
pnpm dev
```

## Submitting Changes

1. Create a branch: `git checkout -b fix/your-fix`
2. Make changes and test locally
3. Commit: `git commit -m "fix: description"`
4. Push: `git push origin fix/your-fix`
5. Open a Pull Request

## Commit Messages

Use prefixes. Refer to the [Convetional Commits spec](https://www.conventionalcommits.org/en/v1.0.0/) for details:

- `fix:` - bug fixes
- `feat:` - new features
- `docs:` - documentation
- `content:` - content updates
